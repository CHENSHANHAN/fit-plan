# FitPlan 健身计划

一款本地优先的 Android 健身计划与训练记录应用，使用 Kotlin 和 Android View 编写。当前版本：**1.5（versionCode 6）**。

## 页面与功能

### 今日训练

- 只显示当天已经安排的训练计划，不再罗列整周内容。
- 显示当前日期、星期和时间。
- 支持力量、有氧或二者组合的当日计划。
- 为每个力量动作录入实际重量（kg），完成后可直接打卡；仅有氧计划也能直接打卡。
- 显示当天的提醒时间，并可统一开启或关闭训练提醒。

### 计划编辑

- 查看并管理周一至周日的训练计划。
- 手动新增、编辑或删除计划，自定义训练名称、动作、组数、次数和提醒时间。
- 力量训练可以不添加；力量与有氧至少填写一项，也可以组合安排。
- 有氧时长填 `0` 或留空表示不安排有氧。
- “从模板导入”内嵌在本页，默认收起；展开后可一键添加或确认替换模板。
- 保存计划或导入模板后，对应训练日的提醒会自动更新。

### 有氧类型

| 类型 | 配置项 |
| --- | --- |
| 爬坡 | 时长、坡度、速度 |
| 跑步 | 时长、速度 |
| 骑车 | 时长、速度 |

切换类型时，编辑页只显示对应配置项；今日计划、计划摘要、通知和训练历史会按实际类型展示。

### 训练历史

- 按日期倒序完整展示训练记录。
- 保留训练时的计划快照、实际重量、有氧类型与参数、打卡状态。
- 显示累计打卡次数和训练记录数量。

### 界面与动效

- 深色橙色健身主题、渐变今日训练头部和精细卡片描边。
- 底部三个标签使用覆盖图标和文字的完整圆角选中背景。
- 页面切换、标签选中与模板展开带轻量动效。

## 内置模板

| 训练日 | 部位 | 提醒时间 |
| --- | --- | --- |
| 周一 | 胸部 | 18:30 |
| 周二 | 背部 | 12:45 |
| 周三 | 肩部 | 18:30 |
| 周四 | 臀腿 | 18:30 |
| 周五 | 手臂 | 18:30 |

模板保留最初设定的动作、组数、次数和爬坡参数，导入后仍可继续编辑。

## 环境要求

- JDK 17
- Android SDK Platform 34
- Android SDK Build Tools 35.0.0
- 最低运行系统：Android 8.0（API 26）
- targetSdk：34

项目使用 Gradle wrapper，无需单独安装 Gradle。主要版本：AGP 8.9.1、Kotlin 2.0.21、Gradle 8.11.1。

## 构建

在项目根目录执行：

```bash
./gradlew :app:assembleDebug
```

Windows 使用：

```bat
gradlew.bat :app:assembleDebug
```

构建产物：

```text
app/build/outputs/apk/debug/app-debug.apk
```

如本机未自动识别 Java 或 Android SDK，请先设置 `JAVA_HOME` 和 `ANDROID_HOME`。

## 安装

连接已开启 USB 调试的手机后：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

也可以把 APK 发送到手机，通过文件管理器安装。首次安装时需要允许对应来源的“安装未知应用”。覆盖安装可保留原有本地数据。

## 使用与权限

1. 初次使用时，五套内置计划会作为当前计划显示；可在“计划编辑”中修改。
2. 仅有氧计划：不填写力量动作，选择有氧类型并填写时长和对应参数，然后保存。
3. 在“今日训练”录入力量动作重量；力量、有氧或组合计划均可点击“完成打卡”。
4. 打开“训练提醒”时，请允许系统通知权限。
5. 如果国产 Android 系统限制后台活动，建议在应用设置中将省电策略设为“无限制”，以保证提醒准时。
6. 点击底部“训练历史”可查看全部历史记录。

## 数据说明

- 训练计划、提醒开关、打卡和历史记录均保存在应用本地 SharedPreferences 中。
- 历史记录保存的是训练发生时的计划快照，后续修改计划不会回写旧历史。
- v1.5 之前的计划和历史没有有氧类型字段，读取时自动按“爬坡”兼容，不会清空原数据。
- 当前版本不包含云同步；卸载应用会清除本地数据。

## 项目结构

```text
app/src/main/java/com/chenshanhan/fitplan/
├── MainActivity.kt              # 单 Activity、自定义底部导航与切换动效
├── TodayFragment.kt             # 今日计划、日期时间、提醒开关
├── PlansFragment.kt             # 整周计划管理与内嵌模板导入
├── HistoryFragment.kt           # 训练历史页面
├── DayAdapter.kt                # 当日动作、重量与打卡
├── HistoryAdapter.kt            # 历史记录卡片
├── EditPlanActivity.kt          # 可选力量与三类有氧配置
├── PlanData.kt                  # 有氧类型、描述与内置模板
├── PlanRepository.kt            # 计划本地存储与旧数据兼容
├── TrainingLogRepository.kt     # 历史、实际重量与有氧快照存储
├── ReminderScheduler.kt         # 定时提醒调度
└── ReminderReceiver.kt          # 通知内容与每周重排
```
